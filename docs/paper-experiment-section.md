# 实验设计与结果分析

## 实验目的

实验验证四个问题：长期记忆是否改善连续任务规划；不同记忆层是否承担不同作用；结构化计划是否满足技能执行约束；记忆选择在噪声和冲突条件下是否稳定。实验使用模拟具身终端，不将规划覆盖率解释为真实机器人硬件完成率。

## 数据集与对比方法

基准数据集包含学习陪伴、家庭教育和家庭服务三类场景。每类场景设置六个用户画像，每个画像包含完整显式、仅风格显式、仅任务项显式和完全隐式四类目标，共 72 条测试样例。每条样例均声明用户记忆、相关记忆键、期望交互风格、期望任务项和领域技能链。

对比方法包括：

- `no_memory`：只使用当前目标，可提取目标中显式给出的风格和任务项。
- `preference_only`：额外读取 profile/preference 记忆。
- `feedback_only`：额外读取 task/feedback 记忆。
- `layered_memory`：联合读取 preference、task、scene 和 feedback 记忆。
- `deepseek_no_memory` 与 `deepseek_layered_memory`：采用相同技能约束的 DeepSeek 外部基线，当前仅完成接口和离线测试，尚未执行正式 API 实验。

72 条样例的显式程度保持平衡，因此无记忆基线并非人为固定为失败：当目标显式给出信息时，它能够产生正确计划；只有隐式信息需要由长期记忆补足。

## 评价指标与统计方法

实验记录记忆检索 precision/recall、偏好匹配率、任务覆盖率、计划可执行率、领域技能链正确率、冲突选择准确率、API 成功率和运行延迟。比例指标报告 Wilson 95% 置信区间，成对 Planner 使用精确 McNemar 检验，并通过 Holm 方法校正多重比较。

任务覆盖率表示计划是否包含数据集声明的期望任务项，是软件模拟中的代理指标。计划可执行率表示技能名和必填参数通过 Skill Registry 校验；技能链正确率进一步判断技能顺序是否适用于对应场景。

## 场景泛化与消融结果

| Planner | 样例数 | 记忆召回率 | 偏好匹配率 | 任务覆盖率 | 可执行率 | 技能链正确率 |
|---|---:|---:|---:|---:|---:|---:|
| no_memory | 72 | 0.00 | 0.50 | 0.50 | 1.00 | 0.92 |
| preference_only | 72 | 0.44 | 1.00 | 0.50 | 1.00 | 1.00 |
| feedback_only | 72 | 0.44 | 0.50 | 1.00 | 1.00 | 1.00 |
| layered_memory | 72 | 1.00 | 1.00 | 1.00 | 1.00 | 1.00 |

结果表明，偏好记忆只补足交互风格，反馈记忆只补足任务项，完整分层记忆同时覆盖两类信息。`layered_memory` 相对 `no_memory` 在偏好和任务指标上各改善 36 个配对样例；精确 McNemar 检验经 Holm 校正后均为 `p < 1.75e-10`。`preference_only` 与完整模型在偏好指标上无差异，`feedback_only` 与完整模型在任务指标上无差异，这与两类记忆的职责划分一致。

## 反馈闭环结果

反馈闭环实验选取 18 个完全隐式目标。写回前只提供偏好记忆，任务覆盖率为 0.00；写入包含历史任务项的反馈后，下一轮任务覆盖率提升到 1.00。两阶段的偏好匹配率、计划可执行率和技能链正确率均为 1.00。

该结果说明反馈记忆进入了下一轮规划依据，支撑“执行结果 -> 长期记忆 -> 后续规划”的闭环机制。

## 鲁棒性结果

在 clean、其他用户与当前用户无关噪声、低置信冲突记忆、低重要度历史记忆四种条件下，`layered_memory` 的偏好匹配率、任务覆盖率、计划可执行率和技能链正确率均为 1.00，冲突记忆未进入最终选择结果。

该结果证明当前规则化 Retriever 能处理实验定义范围内的噪声，但不能外推为对任意自然语言矛盾或长期时间衰减均具有鲁棒性。

## DeepSeek 对照实验设置

DeepSeek 基线使用官方 `deepseek-v4-flash`、非思考模式和 JSON Output。每个 Planner 对每条样例运行五次，共计划执行 720 次 API 请求。结果将按每个样例多数表决进行显著性分析，并单独报告五轮均值、标准差、system fingerprint、提示哈希、token 使用量和延迟。

当前环境未提供 `DEEPSEEK_API_KEY`，因此本节只给出预注册的实验设置，不能报告或推测 DeepSeek 数值。正式运行后应由导出命令自动更新本节对应表格。

## 局限性

第一，数据集为研究者构造的合成任务，尚未包含真实用户交互日志。第二，Retriever 仍采用确定性词项和权重规则，未评估复杂语义等价、长期时间衰减和多轮矛盾演化。第三，Robot Adapter 是模拟终端，不包含感知噪声、动作失败和环境变化。第四，DeepSeek 在线实验尚未执行，当前结论仅覆盖确定性 Planner。
